\# Side Quest – System Context

Project: The Leaning Tower of Regolith (ARC 2026)



\## 1. What This System Is



Side Quest is an XR-mediated supervisory construction challenge in which a human authorizes the final placement of robotic stacking actions.



The robot proposes a placement.

The human evaluates tectonic tolerance (Green / Yellow / Red).

The human authorizes FIX or DROP.

The robot executes.



The system is explicitly asymmetric:

Human = Gatekeeper

Robot = Execution agent

XR = Cognitive mediator
